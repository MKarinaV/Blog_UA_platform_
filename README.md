# BlogUA — Блогова платформа

Flask + SQLite веб-застосунок з повним функціоналом блогу.  
Платформа підтримує систему ролей, модерацію коментарів, створення постів та базову систему адміністрування.

## Встановлення та запуск

Спочатку потрібно встановити необхідні залежності:

```bash
pip install -r requirements.txt

Після цього запустити сервер:

python app.py

Після запуску застосунок буде доступний у браузері за адресою:

http://localhost:5000

Акаунт адміністратора за замовчуванням
Поле	Значення
Логін	admin
Пароль	admin123

Реалізований функціонал
1. Реєстрація та автентифікація
Реєстрація з валідацією імені, email та пароля.
Вхід і вихід із використанням сесій Flask.
Хешування паролів через werkzeug.security.
Захист від входу заблокованих акаунтів.
2. Управління постами
Створення, редагування та видалення постів.
Статуси постів: чернетка / опублікований.
Додавання тегів.
Лічильник переглядів.
Автоматична фільтрація заборонених слів у контенті.
3. Коментування
Додавання коментарів до постів.
Коментарі звичайних користувачів потребують схвалення.
Коментарі адміністратора публікуються відразу.
Видалення власних коментарів.

4. Система ролей і модерація
Роль	Можливості
user	Читання, написання постів та коментарів
moderator	Можливості користувача + модерація коментарів
admin	Повний доступ до управління користувачами, постами та коментарями

Адміністратор може:

блокувати та розблоковувати користувачів
змінювати ролі користувачів
видаляти акаунти разом з постами та коментарями
схвалювати або відхиляти коментарі
видаляти будь-які пости та коментарі

Тестування

Для запуску тестів потрібно виконати:

py -m pytest

Тести перевіряють:

відкриття головної сторінки
доступність сторінки входу
доступність сторінки реєстрації
захист адміністративної панелі від неавторизованого доступу.

База даних SQLite
users
(id, username, email, password_hash, role, is_blocked, bio, created_at)

posts
(id, title, content, tags, author_id, status, views, created_at, updated_at)

comments
(id, post_id, author_id, content, created_at, is_approved)
